The problem

The diff is the least useful part of an agent’s work.

−Agents write most of the code now. Review still reads only the diff.
−A diff shows what changed. Not what was asked, or who asked.
−The reasons are in the conversation, and that stays on one laptop.
+promptlog keeps the conversation with the commits, and shows it in review.

How it works

One command, then nothing new to learn.

  1. 1

    Connect

    Run it once in any folder. It sets up git if needed, recording hooks for Claude Code, and a private Cloudflare Artifacts repo named after the folder. It imports the folder’s past Claude Code sessions, linked to the commits they made, and pushes.

    $ promptlog connect
  2. 2

    Work as usual

    Nothing changes in how you work. Every commit, by you or by an agent, pushes its branch and the conversation behind it, in the background. Each branch is a PR.

    nothing to run
  3. 3

    Review the conversation

    Open the PR page. Every changed line is credited to the turn that wrote it. Each turn shows who asked, what they asked, how Claude replied, and the code it wrote.

    see a real PR ↓

A real PR

Exact, when recorded live

While you work, the hooks keep a before and after snapshot of each file Claude edits. Those lines are credited exactly.

Matched, when not

Agents often edit through Bash scripts, and older sessions were never recorded. For those, promptlog matches each line against the code inside the turn’s own tool calls.

Who, what, and the reply

Each turn shows who asked (you, or another agent), what they asked, what Claude said back, and the code it wrote. Turns that wrote no code fold into one line.

Many agents

Agents talk to each other. promptlog shows it.

While this PR was being built, a second Claude session, “Blog SEO audit”, was using the extension on live sites: Google Search Console, Cloudflare DNS, Bing. Each time it hit a bug, it sent a field report to the session building the extension. Each report is its own turn in the PR, with its sender.

Many agents, one repo

Leases: two agents never edit the same file at once.

Before an agent changes a file, promptlog claims it. If another live agent session holds that file, the edit is refused, and the agent is told who holds it: their branch, what they were asked, and when they were last active. So it works on something else, or messages that agent.

  • Shared across every worktree of the repo, so parallel agents in separate worktrees see each other.
  • Renewed by activity. A lease expires after 15 quiet minutes, and ends when its session ends.
  • Covers Claude’s Edit and Write tools, and Bash commands that write files.
  • promptlog leases lists who holds what. promptlog leases release frees a file by hand.

Built on Cloudflare

Everything after the commit runs on Cloudflare.

No server to run and no API keys anywhere. The repo, the events, the review page and the AI are all Cloudflare.

Your machine

Claude Code sessions

You and any number of agents, working as usual.

commit + push

Cloudflare Artifacts

Private git repo

One per folder. Branches, and the conversation behind every commit.

push event

Queue → Worker

Worker + Container

The Worker reads the repo; a Container runs the viewer. Push events go to a Queue.

Workers AI

DeepSeek + Clef-flash

DeepSeek writes the text. Clef-flash makes the decisions.

serves

Your browser

Review page

Each turn, with the code it wrote.

Artifacts is the repo

Plain git. Conversations are stored next to the commits as git refs, so they travel with a normal push.

A commit is the trigger

Every commit pushes itself to Artifacts in the background. The review page reads the newest version when you open it. Artifacts push events are wired to a Queue for live updates.

AI without keys

Text and decisions run on Workers AI, through the Worker’s own binding. Nothing to sign up for, nothing to leak.

Our own instance runs at promptlog-viewer.mazlix-f8e.workers.dev. It is private: pages need a key.

Try it

One folder, one command.

terminal
$ git clone https://github.com/jkrup/promptlog ~/promptlog
$ cd ~/promptlog && npm install
$ cd ~/code/your-project   # any folder you use Claude Code in
$ ~/promptlog/bin/promptlog connect
example output
Created the private repo "your-project" on Cloudflare Artifacts.
Brought in 6 past Claude Code session(s): 418 turns, linked to 37 commit(s).
Pushed 3 branch(es) (12 MB). From now on every commit pushes itself.
  • Needs Node 22.18 or newer, Claude Code, and a Cloudflare account. Log in once with npx wrangler login.
  • The Artifacts repo is private. Its write token goes to git’s credential store, never to the screen or the repo.
  • To read reviews on your own machine, run promptlog view in the folder.
  • Hooks never block Claude. If recording fails, it logs the error and gets out of the way.

promptlog is open source under the MIT license. Built on Node, with zero runtime dependencies. An entry for Cloudflare’s “Build the next GitHub” contest.
